# Logo afiliasi

Letakkan berkas SVG resmi dari Wikimedia Commons di folder ini dengan nama persis:

- `osis.svg`  — logo OSIS
- `wosm.svg`  — World Scout Emblem (WOSM)
- `sdgs.svg`  — logo Sustainable Development Goals

Selama berkas belum ada, situs menampilkan label teks (OSIS / WOSM / SDGs) sebagai cadangan.
Jangan mengubah bentuk atau warna logo. Logo WOSM dan SDGs adalah merek terdaftar; pakai hanya sebagai
penanda afiliasi/minat, bukan seolah-olah dukungan resmi.
