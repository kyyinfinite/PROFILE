# SEO update for Kyyinfinite portfolio

The original React + Vite portfolio structure and styling have been preserved. SEO metadata was merged into the existing `index.html`; no replacement landing page was used.

## Included
- Canonical URL: `https://www.kyyinfinite.my.id/`
- Robots indexing directive
- Open Graph and Twitter metadata using the existing `public/og-image.jpg`
- Person structured data
- `public/robots.txt`
- `public/sitemap.xml`

## Deploy
1. Replace your repository files with these project files, or copy the updated `index.html` and the two files in `public/` into your existing project.
2. Deploy to Vercel.
3. Check `https://www.kyyinfinite.my.id/robots.txt` and `https://www.kyyinfinite.my.id/sitemap.xml`.
4. In Google Search Console, submit `https://www.kyyinfinite.my.id/sitemap.xml`.

Note: Google indexing is not immediate or guaranteed. Keep the canonical domain consistent with the redirect behavior configured for your domain.
